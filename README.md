## Deploy to GitHub Pages

1. Create a GitHub repository named `SpikeyMikie.github.io`.
2. Copy the contents of this folder into the repository root.
3. Commit and push to `main`.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select `main` and `/ (root)`.
7. Save.

Your site will then be available at:

`https://SpikeyMikie.github.io/`

## Alternative

The included GitHub Actions workflow can deploy the site automatically. If using the workflow, set GitHub Pages to **GitHub Actions** under Settings → Pages.
